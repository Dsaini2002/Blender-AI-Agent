Tell Blender what you want. It builds it, checks it, and fixes it.

Blender AI Agent is an AI helper inside Blender. Just type what you want to create, like “make a campfire.” It builds the scene, takes images to check its work, and tries to fix any problems it finds.

    6 of 6 habits on

    The seventh habit is not a visual switch: after a build, the agent looks at a picture and fixes anything that looks flat, empty or floating. That is the next section.

    It checks its own work

    Some things have no ready-made tool. For these, Gemini writes a build script and Blender runs it. Then the agent takes pictures from four sides and gives them a score. It fixes the script again and again, until the score is good or it runs out of tries.

    1. WriteGemini writes a short build script. It can only use the agent's own tools.
    2. RunBlender runs the script in a safe box: no imports, no file access, and a limit on time.
    3. PictureFour pictures of the new objects from different sides.
    4. ScoreGemini looks at the pictures, gives a score from 0 to 10 and lists what is wrong.
    5. FixThe script is written again using those notes. The old objects are removed first.

      After every task

      • It reads the Blender console for errors and warnings, and ignores the normal messages.
      • It takes a picture of what changed and asks Gemini to check it. Very small jobs, and work that build.iterate already checked, are skipped.
      • If something is wrong, the notes go back to the agent for up to two more tries. If a fix makes things worse, it stops.

      Guardrails

      • Scripts can only use the agent's own tools.
      • A script can delete only the objects it made itself.
      • If a build fails or is cancelled, it is undone. If the AI quota runs out, the agent stops and keeps the best result so far.
      • API keys are read from environment variables and are never shown.

      How to set it up on Windows

      You need Blender 5.2 LTS and one API key. A free Gemini key is enough to start.

      1. Get the code

        git clone https://github.com/Dsaini2002/Blender-AI-Agent.git

      2. Copy the add-on into Blender

        Copy-Item .\Blender-AI-Agent\blender_ai_agent "$env:APPDATA\Blender Foundation\Blender\5.2\scripts\addons\" -Recurse

      3. Add your key, then restart Blender

        setx GEMINI_API_KEY "paste-your-key-here"

        Groq and OpenAI work the same way with GROQ_API_KEY and OPENAI_API_KEY.

      4. Turn it on

        In Blender open Edit, Preferences, Add-ons and enable blender_ai_agent. Press N in the 3D viewport and open the AI Copilot tab.

      5. Ask for something

        make a campfire, add a tent, add a lantern

        A request with several parts is split into steps. Each step shows its progress and the time left.

      6. Check that everything passes

        python run_tests.py

      Good to know

      • Hard subjects, like a car, are built from simple shapes and ready-made materials. Expect clean and easy-to-recognise results, not photographs.
      • A free Gemini key has a small daily limit. Set BLENDER_AI_AUTOVERIFY=console to keep the automatic check but skip the picture check.
      • On Windows the console check reads Python messages, but not the low-level Blender warnings.
      • The ready-made materials are made for Blender 5.2 LTS.
